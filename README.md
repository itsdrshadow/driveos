# DriveOS releases

Release APKs of DriveOS, the car launcher. The source code is private; this repository only
holds the releases that the app's built-in updater downloads.

Pick the APK on the [latest release](../../releases/latest):

- `arm64-v8a`: most phones and newer 64-bit head units
- `armeabi-v7a`: older / 32-bit head units
- `universal`: works on every device (bigger)
